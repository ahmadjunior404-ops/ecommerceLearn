# Project Guidelines & Instructions

## 1. Mandatory Progress Documentation
- **Continuous Tracking**: Any and all changes made to the codebase (feature additions, bug fixes, UI adjustments, styling updates, refactors, dependencies, or architectural shifts) **MUST** be recorded in `Progress.md`.
- **Dual Synchronization**: Ensure both `Progress.md` at the workspace root and `vite-project/Progress.md` remain synchronized with the latest entries.
- **Entry Details**: Whenever updating `Progress.md`, record:
  - Date / Timestamp
  - Description of change and user request context
  - Files modified and specific components affected
  - Verification & build status
